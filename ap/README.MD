



Pure Cycles 🚲


About the Project

Pure Cycles is a simple bicycle shopping website created using HTML and CSS. It displays bicycle categories, featured bikes, navigation links, and footer information in a clean layout.

Features
Header Section: Website name, search, account, and cart.
Navigation Bar: Bikes, accessories, new arrivals, sale, and about us.
Hero Banner: Introduces the bicycle collection.
Featured Gear: Displays four bicycle categories:
City Bike
Road Bike
Mountain Bike
Electric Bike
Promotional Banner: Encourages users to explore the latest bicycle collection.
Footer Section: About us, customer support, contact, and social media links.
Technologies Used
HTML5
CSS3
External bicycle images

How to Run the Project
Download or clone the project.
Save the HTML code in a file named index.html.
Open the index.html file in any modern web browser.
Explore the different sections of the Pure Cycles website.
Purpose

The purpose of this project is to practice HTML tables, CSS styling, images, links, buttons, and basic webpage layout.
